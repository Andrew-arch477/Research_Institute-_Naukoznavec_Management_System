# Research_Institute_Naukoznavec_Management_System
An example of a management system in Django that demonstrates the basics of working with Django.

## Requirements
* Python 4
* Django 4
* HTML
* Bootstrap

## Main features
* User authentication (login) out of the box
* CRUD operations
* Bootstrap 5 static files
* Easy to undertand forms with validation.

## Installation
1. Install the required libraries
```bash
pip install django
```

2. Clone the Repository
```bash
git clone https://github.com/xok9ty/dj_project.git
```

3. Run Migrations
```bash
python manage.py makemigrations

python manage.py migrate
```

4.  Start the server
```bash
python manage.py runserver
```

## How to use
1. Befor running the server insert this comand:
```bash
python manage.py createsuperuser
```
